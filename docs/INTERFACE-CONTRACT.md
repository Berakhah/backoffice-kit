# BackOffice Kit — Interface Contract

**Version 0.1 · 27 August 2026 · Status: agreed**
Authoritative surface of `bok-core` and `bok-ui`. Derived from
`docs/superpowers/specs/2023-11-14-backoffice-kit-design.md`.

## How to use this document

The four consumer repos design against this contract; they do not build the substrate. Any plan task
in `agent-perimeter`, `ledger-sense`, `selector-drift` or `ground-truth` that names a `bok_core.*` or
`bok-ui` symbol must find it here. **If a symbol is not in this document, it does not exist, and the
plan task that needs it is blocked on an amendment here — not on a local workaround.**

This document is **versioned and additive**. `bok-core` is on PyPI, so an addition is a minor version
bump. Removals and signature changes are breaking and require an entry in §9.

## 1. `bok_core.boundary`

Three orthogonal axes. Two enforcement points. Nothing here is optional for any consumer.

### 1.1 `sensitivity`

```python
class Sensitivity(StrEnum):
    PUBLIC = "PUBLIC"                            # already public; may reach a free tier
    SYNTHETIC = "SYNTHETIC"                      # generated by us; may reach a free tier
    REDACTED = "REDACTED"                        # verified-redacted; per-project opt-in required
    CLIENT_CONFIDENTIAL = "CLIENT_CONFIDENTIAL"  # never a free tier; hard fail

class Trust(StrEnum):
    TRUSTED = "TRUSTED"
    UNTRUSTED = "UNTRUSTED"      # attacker-authored content; forces schema + tool denial

class SensitivityViolation(Exception): ...

class Labelled(Generic[T]):
    value: T                     # str, bytes, Path, or an open file handle
    sensitivity: Sensitivity
    trust: Trust = Trust.TRUSTED
```

**`Labelled` wraps bytes, `Path` and file handles, not only prompts.** The label attaches where a
file is opened. Attaching it at gateway entry is too late.

### 1.2 `policy`

```python
class ProviderCapability(BaseModel):
    provider_id: str
    reachable: Claim[bool]
    card_required: Claim[bool]
    trains_on_data: Claim[bool] | None       # None == unverified == treated as True
    commercial_use: Claim[bool] | None       # None == unverified == treated as False
    structured_output: Claim[bool]
    tools_deniable: Claim[bool]
    vision: Claim[bool]
    fingerprint_exposed: Claim[bool]
    limits: Quota
    live_model_ids: list[str]
    terms_url: str
    terms_retrieved_at: datetime
    terms_sha256: str
    verified_at: datetime | None

class CallContext(BaseModel):
    commercial: bool = False

def check(payload: Labelled[Any], context: CallContext, provider: str) -> None:
    """Raises SensitivityViolation. The message cites the Claim's Source."""
```

Refusal messages **quote their evidence** — the terms URL, retrieval date and the quoted sentence
carried by the `Claim`. A refusal a client's counsel cannot audit is not a control.

**Fail closed on unknown.** `trains_on_data is None` behaves as `True`; `commercial_use is None`
behaves as `False`. An unverified provider is ineligible above `PUBLIC` / `SYNTHETIC`.

### 1.3 `redact`

```python
class RedactionResult(BaseModel):
    text: str
    verified: bool               # False if any original identifier survived
    surrogates: dict[str, str]
    failures: list[str]

def redact(payload: Labelled[str]) -> RedactionResult: ...
```

Detect → stable surrogate (structure survives) → **verification pass that re-scans the output**.
`verified` is a field on a result the caller must destructure, never a bare bool that can be dropped.

### 1.4 `fingerprint`

```python
class SecretFingerprint(BaseModel):
    sha256: str
    entropy: float
    prefix: str
    last4: str
    location: str

    def __init__(self, raw: str, location: str) -> None: ...
```

The constructor accepts the raw value and **structurally guarantees non-retention**: no attribute
holds it, `__repr__` / `__str__` cannot expose it, it is unreachable after construction.

Consumers: `agent-perimeter` (constraint 3 — never validate a discovered secret), `ledger-sense`.

### 1.5 `egress` — the second enforcement point

```python
class Plane(StrEnum):
    CLIENT = "CLIENT"        # compose-only, no third-party processor
    DEMO = "DEMO"            # SYNTHETIC / PUBLIC only, hostable anywhere

def guard_write(path: Path, payload: Labelled[bytes], plane: Plane) -> None:
    """Raises SensitivityViolation. Refuses CLIENT_CONFIDENTIAL to a non-CLIENT plane,
    and refuses any payload whose redaction verification did not pass."""
```

**Required by `selector-drift`** (evidence write path: capture → redact → verify → store, quarantine
on failure) and by `agent-perimeter` (no raw secret ever persisted). Neither is a gateway concern.
Consumers route their write paths through this rather than writing bespoke guards.

## 2. `bok_core.provenance`

### 2.1 `Claim`

```python
class Method(StrEnum):
    DETERMINISTIC = "DETERMINISTIC"
    MODEL = "MODEL"
    HUMAN = "HUMAN"
    DERIVED = "DERIVED"

class Derivation(StrEnum):
    SCHEMA = "SCHEMA"
    DESCRIPTION = "DESCRIPTION"
    PROBE = "PROBE"
    ARTIFACT = "ARTIFACT"

class CalibrationState(StrEnum):
    UNCALIBRATED = "UNCALIBRATED"
    CALIBRATED = "CALIBRATED"

class Calibration(BaseModel):
    state: CalibrationState
    basis: str            # "synthetic corpus only" vs "400 real labelled fields"
    curve_id: str | None
    n: int | None

class Claim(BaseModel, Generic[T]):
    value: T
    source: Source
    method: Method
    derivation: Derivation | None = None
    confidence: float | None = None
    calibration: Calibration | None = None
    observed_at: datetime
    parents: list["Claim"] = []
    caveat: str | None = None
```

### 2.2 `Source` — discriminated union, seven variants

```python
FileSource(path: str, line: int)                       # agent-perimeter
DocumentSource(path: str, page: int, bbox: BBox)       # ledger-sense
UrlSource(url: str, retrieved_at: datetime)            # agent-perimeter, policy citations
ModelSource(ledger_call_id: str)                       # all four -- FK into gateway.ledger
HumanSource(who: str, at: datetime)                    # ledger-sense, selector-drift
RuleSource(authority: str, citation: str,
           confirmed_by: str, confirmed_at: datetime)  # ledger-sense
DomSource(snapshot_id: str, selector: str, rung: int)  # selector-drift
```

`FileSource` and `DocumentSource` are separate types by design. Merged, "no bbox because this is
source code" would be indistinguishable from "no bbox because extraction failed."

### 2.3 Invariants — enforced by `bok-core`, re-testable by consumers

| # | Invariant | Consumer that depends on it |
|---|---|---|
| I1 | `DERIVED` confidence ≤ `min(parent.confidence)` | all four |
| I2 | `MODEL` with `confidence is None` cannot render as fact | all four |
| I3 | **`DETERMINISTIC` implies `confidence is None`** | `selector-drift` §3.5 |
| I4 | `caveat` propagates to children verbatim | `ground-truth` §9 |
| I5 | **`Claim[Decimal]` serialises `value` as a string, never a float** | `ledger-sense` §4.1.2 |
| I6 | I1 and I4 hold at chain depth ≥ 5 | `ground-truth`, `ledger-sense` |

### 2.4 `render`

```python
def to_rail(claim: Claim[Any]) -> RailPayload:
    """Serialisation consumed by bok-ui's <ProvenanceRail>. Parents nest."""
```

## 3. `bok_core.gateway`

### 3.1 `lanes`

```python
def resolve(lane: str) -> Handle:
    """Resolve a lane to a call handle. NEVER takes or returns a model name.
    With zero eligible providers, returns the lane's deterministic fallback handle."""

def eligible(lane: str) -> list[str]:
    """Provider ids satisfying the lane's requirement predicate. May be empty."""

def unsatisfied_requirements(lane: str) -> list[str]:
    """Which requirement no provider met. Drives the health strip's explanation."""
```

`models.yaml` shape:

```yaml
lanes:
  judge:
    requires: {structured_output: true, tools_deniable: true}
    max_sensitivity: PUBLIC
    fallback: local-fallback        # REQUIRED -- validation fails without it
```

A lane is a **capability predicate**, never a provider list. The eligible set derives from `policy`.
An unexpected inventory answer edits one data row; no code changes.

### 3.2 `router`

```python
class CacheMode(StrEnum):
    ENABLED = "ENABLED"
    DISABLED = "DISABLED"

class FailoverMode(StrEnum):
    ENABLED = "ENABLED"
    DISABLED = "DISABLED"

def call(
    handle: Handle,
    payload: Labelled[str],
    context: CallContext,
    *,
    response_schema: type[BaseModel] | None = None,
    tools_disabled: bool = False,
    cache: CacheMode = CacheMode.ENABLED,
    failover: FailoverMode = FailoverMode.ENABLED,
) -> Response:
    """Raises SensitivityViolation before dispatch.
    If payload.trust is UNTRUSTED, refuses to dispatch unless response_schema is
    provided AND tools_disabled is True. Enforced, not defaulted."""
```

| Parameter | Required by | Why |
|---|---|---|
| `response_schema` + `tools_disabled` under `UNTRUSTED` | `agent-perimeter` B6 | *"otherwise B6's mitigation is a prompt, and a prompt is not a security boundary"* |
| `cache=DISABLED` | `ground-truth` §12 | A cache hit returns an identical response for replicates 2–5, fabricating zero variance and destroying B7's measurement |
| `failover=DISABLED` | `ground-truth` benchmark execution | Model identity is the variable under study. A silent failover attributes model A's output to model B and corrupts the benchmark invisibly |

### 3.3 `governor`

```python
class Quota(BaseModel):
    rpm: int | None
    tpm: int | None
    rpd: int | None

def remaining(provider: str) -> Quota:
    """PUBLIC QUERY, not only internal enforcement. ground-truth's scheduler asks
    before dispatching each sweep batch."""
```

Persistent token buckets per provider, exponential backoff with full jitter on 429, priority-lane
queue, hard daily ceiling that fails closed. Quota consumed is exported as a Prometheus metric.

### 3.4 `ledger` — a queryable table, not structured logs

```sql
CREATE TABLE bok_ledger (
  call_id               TEXT PRIMARY KEY,   -- stable; consumers FK against this
  model_id              TEXT NOT NULL,
  provider              TEXT NOT NULL,
  lane                  TEXT NOT NULL,
  sensitivity           TEXT NOT NULL,
  prompt_hash           TEXT NOT NULL,
  response_fingerprint  TEXT,               -- NULL where the provider exposes none
  latency_ms            INTEGER NOT NULL,
  tokens                INTEGER,
  quota_consumed        INTEGER,
  observed_at           TIMESTAMPTZ NOT NULL
);
```

```python
def record(...) -> str: ...                       # returns call_id
def query(**filters) -> list[LedgerRow]: ...
```

**Hard dependency for `ground-truth`**: `outputs.ledger_call_id` is a foreign key into this table.
Without it, B6 fingerprint tracking and B8 provider attribution are impossible and the regression
module has no substrate. `response_fingerprint` is nullable on purpose — free tiers often expose
none, and `ground-truth` must report that rather than imply a version it cannot pin.

### 3.5 `probe` and `cache`

```python
def probe_all(ttl: timedelta) -> HealthStrip: ...        # startup capability probe
def invalidate(pattern: str | None = None) -> int: ...   # cache invalidation
```

Cache key is content-addressed: `hash(model + lane + normalised prompt + params)`. SQLite-backed,
explicit TTL.

## 4. `bok_core.findings` and `bok_core.obs`

```python
class Severity(StrEnum):
    CRITICAL = "CRITICAL"
    HIGH = "HIGH"
    MEDIUM = "MEDIUM"
    LOW = "LOW"
    INFO = "INFO"

class Finding(BaseModel):
    id: str
    severity: Severity
    title: str
    claim: Claim[Any]
    taxonomy_refs: list[str] = []
    logical_location: str | None = None
    partial_fingerprints: dict[str, str] = {}
    properties: dict[str, Any] = {}

def to_sarif(findings: list[Finding]) -> dict:
    """SARIF 2.1.0. logicalLocations, partialFingerprints and properties are
    first-class, not only physicalLocation."""
```

**Two consumer classes, and the vocabulary must serve both.** `agent-perimeter` emits security
findings about a live server (no natural `physicalLocation` — B7). `selector-drift` emits
**data-quality violations** (row counts, null rates, schema drift, distribution shift) through the
same ladder and the same emitter. Neither the ladder nor the emitter may assume a scanner's
vocabulary.

`bok_core.obs` — `structlog` JSON with correlation ids; `prometheus-client` metrics. Quota consumed
is a first-class metric.

## 5. `bok_core.testing.degraded`

```python
@contextmanager
def blackout() -> Iterator[None]:
    """Every lane raises ProvidersUnavailable. Defeats the response cache, the probe
    TTL cache, the fallback chain, and any local-fallback that is not deterministic."""

def assert_blackout_complete() -> None:
    """Asserts no code path reached a provider under blackout. THE shared test."""

def census(inventory: list[Capability]) -> CensusReport:
    """Computes the model-dependent ratio in the caller's own declared unit and
    renders it for docs/methodology.md. REPORTS ONLY -- never asserts a threshold."""
```

**There is no shared `≥70%` assertion.** `00` §2.2 and §7 use two different denominators for the
same test, the four consumers have four incommensurable units, and a class-count ratio improves when
you split a check and worsens when you ship a valuable escalation. Each repo asserts its own floor:

| Repo | Floor | Unit |
|---|---|---|
| `agent-perimeter` | ≥90% | check classes |
| `ledger-sense` | binary | deterministic extraction + validation of digital PDFs completes end to end |
| `selector-drift` | majority | mutation classes healed by rungs 1–4 |
| `ground-truth` | **zero** | phase 2 makes no gateway calls at all (AST assertion) |

Every repo publishes its floor and its unit in `docs/methodology.md`.

## 6. `bok-ui` v0.1 — available end of week 3

### 6.1 Tokens and contracts — land whole

OKLCH warm-graphite ramp (paper `oklch(0.985 0.004 85)`, ink `oklch(0.22 0.012 85)`, twelve steps);
four product accents; `critical/high/medium/low/info` and `verified/modelled/unverified` semantic
scales; Newsreader / Geist Sans / IBM Plex Mono self-hosted with tabular numerals; 4px base; radius
6/2/0; **density mechanism** shipping `comfortable` and `compact`; visible focus rings; **glyph +
text label on every semantic colour**; `prefers-reduced-motion`; **print stylesheet as standalone
CSS** (its first consumer is `agent-perimeter`'s server-rendered `report/html.py`, which never
imports React).

### 6.2 Nine components

`Claim` · `ProvenanceRail` · `SeverityBadge` · `FindingsTable` · `EvidencePane` (text/code adapter
only) · `ConfidenceMeter` · `EmptyState` · `ErrorState` · `Skeleton`

Non-obvious props:

```tsx
<EmptyState scope={{ measured: 24, skipped: 3, reason: "no scope file" }} />
// Renders a DENOMINATOR, never a celebration. Required by AP, SD and GT alike.

<ConfidenceMeter calibration={Calibration} />   // the object, never a float

<EvidencePane adapter={TextAdapter} ranges={[...]} />
// The adapter interface is designed in v0.1; only the text/code adapter ships.
```

`FindingsTable` is virtualised, column-resizable, keyboard-navigable, CSV/JSON export. A separate
**roving-tabindex list-navigation primitive** ships alongside it — `ledger-sense`'s review queue is a
queue (`J`/`K`/`Enter`/`E`/`R`, fifty exceptions mouse-free), not a table.

### 6.3 Deferred — build locally, propose promotion on second use

| Artifact | Available | Consumer that first needs it |
|---|---|---|

| `bok_core.provenance` | week 0 | `agent-perimeter` week 1 |

| `bok_core.gateway` | week 0 (with an **empty** provider inventory) | `agent-perimeter` week 2 judge escalation |
| `bok_core.findings` / `obs` | week 0 | `agent-perimeter` week 2 |
| `template/` | week 0 | all four, at scaffold time |
| `providers.yaml` populated | **before week 4** | `ledger-sense` week 5 |
| `bok-ui` v0.1 | **end of week 3** | `agent-perimeter` week 4 |
| Deferred `bok-ui` components | weeks 5 / 13 | see §6.3 |

**If `backoffice-kit` slips**, the pre-authorised fallback is a local `_bok_shim.py` implementing the
minimum surface the blocked repo needs, carrying a `ponytail:` comment naming the upgrade path — the
pattern `ground-truth` already specifies. On the web side, plain React plus a local `Claim` shim.
**A shim is never acceptable for `boundary`**: `ledger-sense` explicitly re-tests the boundary against
the published package because a mocked boundary stops nothing at 2am in week 11.
